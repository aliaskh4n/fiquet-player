# fiquet player

Мобильный плеер личной библиотеки fiquet. [Открыть сайт](https://aliaskh4n.github.io/fiquet-player/).

В каталоге 1 071 доступный MP3, включая разговорные записи. 135 музыкальных записей собраны отдельно, 16 отмечены как полные версии. Для 187 медиа сохранены только метаданные: Telegram не выдаёт файл через публичный предпросмотр.

## Возможности

- Адаптивный интерфейс, мини-плеер и разворачиваемый экран трека.
- Поиск по названию, подписи и ссылке на Telegram-публикацию, в том числе по связанным ответам с названием песни.
- Очередь, прослушивание следующей, перемешивание, повтор, перемотка и управление через Media Session.
- Избранное и восстановление позиции на этом устройстве, без аккаунта.
- Поиск текста в LRCLIB с ручным выбором совпадения, импорт своего TXT/LRC, подсветка строк и настройка смещения. Слова и тайминги оригинала могут отличаться от кавера.
- Фотографии из открытых публикаций автора как обложки. Источник фотографии доступен в меню записи и в `assets/photos.json`.
- Telegram WebApp SDK: готовность, разворачивание, тема, безопасные отступы, кнопка назад и тактильный отклик. Подключение к конкретному боту отдельно не выполнялось.

## GitHub Pages

Сайт не требует сервера, ключей API или сборки. В Settings → Pages источником должен быть GitHub Actions. Workflow `.github/workflows/pages.yml` публикует содержимое при push в `main`.

Все пути относительные: сайт работает в `/fiquet-player/`. В `data/catalog.json` находится каталог, в `media/` — 1 071 MP3. База SQLite и исходные видео сюда не загружаются: они сохранены в локальном архиве. Медиаданные не кешируются service worker автоматически; для сохранения записи используйте «Скачать MP3».

Чтобы открыть сайт локально, запустите `python3 -m http.server 8080` в этой папке. Открытие `index.html` как `file://` не подходит для ES-модулей и JSON-каталога.

## Telegram Mini App

Для запуска внутри Telegram укажите HTTPS-адрес сайта в настройках своего бота через BotFather. Плеер не использует `initData` как авторизацию и не запрашивает доступ к сообщениям. Сам GitHub Pages-сайт доступен и в обычном браузере.

Избранное, позиция и выбранные тексты сохраняются в браузере текущего устройства. Полные тексты LRCLIB не включены в репозиторий: поиск выполняется только по нажатию пользователя. Нативный фоновой режим iOS/Android зависит от клиента Telegram и отдельно на физическом устройстве не проверен.
