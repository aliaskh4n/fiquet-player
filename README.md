# fiquet player

[Открыть плеер](https://aliaskh4n.github.io/fiquet-player/). Каверы и акустические исполнения fiquet из открытых публикаций.

## Музыкальный каталог

Проверены все 1 071 доступные MP3, осталось **241 музыкальная запись**, включая 16 отмеченных полных версий. Из плеера исключены 501 запись с преобладающей речью, 10 немузыкальных/сторонних роликов и 319 записей, где кавер не подтверждён. 7 ошибочных попаданий убраны из прежней музыкальной подборки, а среди неподписанных аудио найдено 113 дополнительных музыкальных записей.

Это консервативная автоматическая проверка полного звука через Apple SoundAnalysis с дополнительным просмотром кадров, подписей и распознаванием речи у спорных примеров. Она не равнозначна ручному прослушиванию всего архива. Результаты: [data/curation-report.json](data/curation-report.json). У 92 музыкальных публикаций сохранены только метаданные, Telegram не выдаёт файл через публичный предпросмотр.

Все оригиналы, включая исключённые голосовые, остались в локальной SQLite. На сайт выгружаются только выбранные MP3 и JSON-каталог, около 182 МБ. В репозитории нет SQLite, исходных видео, транскриптов проверки, ключей API или серверных секретов.

## Плеер и караоке

- Интерфейс в стиле Telegram, системный шрифт, компактные списки, безопасные отступы и кнопка назад.
- Цвета фона, секций, текста, кнопок, заголовка и нижней панели берутся из `Telegram.WebApp.themeParams` и обновляются при `themeChanged`. В обычном браузере доступны системная, светлая и тёмная темы.
- Избранное, очередь, переходы, перемешивание, повтор, перемотка, Media Session и восстановление позиции без автозапуска.
- Отдельный экран караоке: крупные строки, выделение текущей, автопрокрутка, нажатие для перехода к строке, возврат к текущей строке после ручной прокрутки. Enhanced LRC поддерживает реальные пословные тайминги; обычный LRC подсвечивается построчно.
- При открытии караоке выполняется поиск LRCLIB. Автовыбор требует совпадения названия и оригинального исполнителя; иначе текст выбирается вручную. Полные тексты не включены в репозиторий.
- Для двух полных каверов («Утро», «Немерено») подготовлены автоматические тайминги по самому аудио. Публикуются только номера строк и времена; текст при открытии загружается из LRCLIB и сверяется по SHA-256. Автотайминги могут быть неточными.
- Тайминги оригинала обозначены отдельно: темп, начало и слова кавера могут отличаться. Можно изменить смещение или записать начало каждой строки под конкретный кавер. Тайминги сохраняются на устройстве. Автоматическая синхронизация с вокалом не заявляется.
- Импорт собственных TXT/LRC до 200 КБ. Полный текст без таймингов можно читать и синхронизировать вручную.
- 19 фотографий из открытых публикаций как обложки; источник доступен в меню и `assets/photos.json`.

Избранное, тексты и тайминги сохраняются в браузере текущего устройства. Это неофициальный плеер.

## GitHub Pages и Telegram

Сайт работает без сервера в `/fiquet-player/`. Settings → Pages → GitHub Actions. Workflow `.github/workflows/pages.yml` публикует содержимое после push в `main`. Версии JS/CSS и импортов ES-модулей добавляются в URL автоматически при экспорте; service worker обновляет интерфейс и каталог, аудио не кеширует массово.

Для локального просмотра запустите `python3 -m http.server 8080` в этой папке. `file://` не подходит для ES-модулей/JSON.

Для запуска внутри Telegram укажите HTTPS-адрес сайта в настройках своего бота через BotFather. Привязка к конкретному боту не выполнялась. `initData` не используется как авторизация. Фоновое воспроизведение на физическом телефоне зависит от клиента Telegram и отдельно не проверялось.
