# fiquet player

[Открыть плеер](https://aliaskh4n.github.io/fiquet-player/). Каверы и акустические исполнения fiquet из открытых публикаций.

## Музыкальный каталог

Проверены все 1 071 доступные MP3. В плеере **241 музыкальная запись**, включая 16 отмеченных полных версий. Исключены 501 запись с преобладающей речью, 10 немузыкальных или сторонних роликов и 319 записей, где кавер не подтверждён. Оригиналы сохранены в локальной SQLite.

Это автоматическая проверка полного звука через Apple SoundAnalysis с дополнительным просмотром кадров, подписей и распознаванием речи у спорных примеров. Она не равнозначна ручному прослушиванию всего архива. Результаты: [data/curation-report.json](data/curation-report.json). У 92 музыкальных публикаций сохранены только метаданные: Telegram не выдаёт файл через публичный предпросмотр.

## Автоматический текст и караоке

Все **241 записи обработаны**. Для **127** подготовлены совпадения с текстом и тайминги по самому исполнению. У **114** надёжное совпадение не подтверждено. Подробности: [data/lyrics-report.json](data/lyrics-report.json).

Текст загружается автоматически при выборе песни. Поиска текстов, ручного выбора, импорта и настройки таймингов в интерфейсе нет. Экран караоке выделяет текущую строку, плавно прокручивается и позволяет нажать на строку для перемотки. Там, где распознаны все слова строки, есть пословная подсветка; остальные строки выделяются целиком.

Подготовка выполнена заранее: распознавание аудио через OpenAI API, определение песни, сопоставление распознанных слов с LRCLIB и дополнительное локальное распознавание слабых записей. Тайминги автоматические и могут иметь погрешность. Неподтверждённые записи показывают, что текст пока недоступен.

В репозитории хранятся ссылки на записи LRCLIB, SHA-256 текста, индексы строк и слов и их времена. Полные тексты, промежуточные расшифровки и API-ключи не публикуются. Браузер загружает текст из LRCLIB и сверяет контрольную сумму перед применением таймингов. Если сервис недоступен или текст изменился, плеер сообщает об этом и повторяет загрузку при следующем открытии. Загруженный текст кешируется только на текущем устройстве.

## Плеер

- Цвета Telegram через `Telegram.WebApp.themeParams`, обновление при `themeChanged`, безопасные отступы и кнопка назад. В браузере доступны системная, светлая и тёмная темы.
- Избранное, очередь, перемешивание, повтор, перемотка, Media Session и восстановление позиции без автозапуска.
- Поиск **записей** по названию, подписи и ссылке на Telegram-пост.
- 19 фотографий из открытых публикаций как обложки. Источники доступны в меню трека и `assets/photos.json`.

Это неофициальный плеер. В репозитории нет SQLite, исходных видео, личных Telegram-сессий или серверных секретов.

## GitHub Pages и Telegram

Сайт работает без собственного сервера в `/fiquet-player/`. GitHub Actions публикует содержимое после push в `main`. Версии JS, CSS и ES-модулей добавляются в URL при экспорте. Service worker обновляет интерфейс и каталог, аудио не кеширует массово.

Для локального просмотра запустите `python3 -m http.server 8080` в этой папке. `file://` не подходит для ES-модулей и JSON.

Для запуска внутри Telegram используется HTTPS-адрес сайта. Привязка к конкретному боту не выполнялась. `initData` не используется как авторизация. Фоновое воспроизведение на физическом телефоне отдельно не проверялось.

Источники: [@woeiwjw](https://t.me/woeiwjw), связанный старый [SoundCloud-профиль](https://soundcloud.com/d-d-55812050), [LRCLIB](https://lrclib.net/). Полнота по всему интернету не подтверждена.
