# fiquet player

[Открыть плеер](https://aliaskh4n.github.io/fiquet-player/). Каверы и акустические исполнения fiquet из открытых публикаций.

## Музыкальный каталог

Проверены все 1 071 доступные MP3. В плеере **241 музыкальная запись**, включая 16 отмеченных полных версий. Исключены 501 запись с преобладающей речью, 10 немузыкальных или сторонних роликов и 319 записей, где кавер не подтверждён. Оригиналы сохранены в локальной SQLite.

Это автоматическая проверка полного звука через Apple SoundAnalysis с дополнительным просмотром кадров, подписей и распознаванием речи у спорных примеров. Она не равнозначна ручному прослушиванию всего архива. Результаты: [data/curation-report.json](data/curation-report.json). У 92 музыкальных публикаций сохранены только метаданные: Telegram не выдаёт файл через публичный предпросмотр.

## Готовые субтитры

Для **1071 имеющихся аудиофайлов** подготовлены статические JSON/VTT. Они сохранены в локальной SQLite и загружены в репозиторий: `assets/subtitles/<id>.json` и `<id>.vtt`. [Скачать все субтитры одним архивом](data/fiquet-subtitles.zip). В плеере остаются 241 отобранная музыкальная запись; разговорные аудио скрыты из каталога.

Для музыкальных записей основа — опубликованный текст исходной песни. Построчные тайминги подготовлены локально по звуку конкретного исполнения с проверкой по сохранённым словам. Учитываются спетые фрагменты, повторы припевов и разговорные вступления. При прослушивании плеер загружает готовый JSON с GitHub Pages.

Экран текста показывает целые строки. Первая строка видна ещё до начала вокала. Текущая строка выделяется и плавно перемещается в центр; подсветка сохраняется до следующей строки, включая протяжные ноты. Нажатие на строку перематывает запись. Для **177** музыкальных записей найденный текст сопоставлен с исполнением, включая все 16 полных каверов. Пропущенные промежуточные строки восстановлены из источника и привязаны к звуку; строки больше не отбрасываются только из-за ошибок в нескольких распознанных словах.

Сырой результат распознавания не используется как текст музыкальных записей. Если исходная песня или её тайминги не подтверждены, плеер сообщает, что точный текст пока не найден. Ссылка на источник и SHA-256 исходного текста сохранены рядом с таймингами; SHA-256 MP3 связывает их с нужным аудио. Сводка: [data/subtitles-report.json](data/subtitles-report.json). Сопоставление автоматическое; ручная проверка каждого слова и полнота всех спетых строк не заявляются. Субтитры исключённых разговорных записей остаются отдельными расшифровками в архиве.

Поиск текстов, OpenAI и распознавание в браузере отсутствуют. API-ключи не публикуются.

## Плеер

- Цвета Telegram через `Telegram.WebApp.themeParams`, обновление при `themeChanged`, безопасные отступы и кнопка назад. В браузере доступны системная, светлая и тёмная темы.
- Избранное, очередь, перемешивание, повтор, перемотка, Media Session и восстановление позиции без автозапуска.
- Поиск **записей** по названию, подписи и ссылке на Telegram-пост.
- 19 фотографий из открытых публикаций как обложки. Источники доступны в меню трека и `assets/photos.json`.
- На главном экране — страницы fiquet в Telegram, Pinterest, TikTok, Instagram и оба профиля SoundCloud.

Это неофициальный плеер. В репозитории нет SQLite, исходных видео, личных Telegram-сессий или серверных секретов.

## GitHub Pages и Telegram

Сайт работает без собственного сервера в `/fiquet-player/`. GitHub Actions публикует содержимое после push в `main`. Версии JS, CSS и ES-модулей добавляются в URL при экспорте. Service worker обновляет интерфейс и каталог, аудио не кеширует массово.

Для локального просмотра запустите `python3 -m http.server 8080` в этой папке. `file://` не подходит для ES-модулей и JSON.

Для запуска внутри Telegram используется HTTPS-адрес сайта. Привязка к конкретному боту не выполнялась. `initData` не используется как авторизация. Фоновое воспроизведение на физическом телефоне отдельно не проверялось.
